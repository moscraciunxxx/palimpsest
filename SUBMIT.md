# How to submit Palimpsest (deadline: 14 Aug 2026, 11:45pm PDT)

The project is ready to run. Devpost still needs you — a student — to press Submit.

## 1. Run it locally (for the video)

```bash
npm install
npm run dev
```

Demo path that hits every judging axis in about 90 seconds:

1. Prologue — “Two hands. One leaf. Neither invented.”
2. **Enter the scriptorium** → case **06 Palimpsest** is already on the table, on **Undertext**.
3. Drag the brass rule. The register stays; the psalm fluoresces. Open **Later hand**, then **Raking** and move the lamp. Click the leaf for the probe.
4. **Read** — diplomatic text is already open on a teaching leaf. Point at the holes. Export **First-aid packet**.
5. **Forge** — oxblood words are labeled FORGERY — NOT EVIDENCE. That column is never the page.
6. **Talk → “Show me the undertext.”** then **“What is the sentinel?”**
7. **Lessons**. Stop on *Two inks, one leaf* and *The sentinel*.
8. Optional: **01 Tenure** and **05 Inheritance** to show the tool is not only a palimpsest.

Record the screen. Keep it under two minutes. Judges skim.

## 3. Prize categories this project is built to contest

You may only win one named prize, but the write-up should make judges *feel* several:

- **Best Use of Machine Learning** — unsupervised density, paper-relative unmixing, structure-tensor sentinel, RTI-lite raking
- **Most Innovative** — recovery that refuses to hallucinate legal text; two hands unmixed, never a completed psalm
- **Most Impactful / Sustainability AI** — climate-lost identity documents
- **AI for Education** — the eleven-lesson studio
- **Best Web AI App** — the scriptorium
- **Conversational AI** — the archivist
- **Data-Driven Insights** — metrics, entities, diplomatic edition
